# 学习助手（child-practice）

**作者：狮子老爸** · GitHub：[@shizilaoba001-collab](https://github.com/shizilaoba001-collab)

根据孩子的学习进度和实际错题，制作下一套可打印的语文数学练习。**公开开源 · MIT许可证 · 版本0.1.2**

给能读写本地文件、运行Python且支持Skill的AI工具使用。由AI问必要信息、设计新题，脚本保存本地学习档案并生成独立题目/答案PDF。无需维护者替每个家庭出卷。

本包不调用任何模型API；使用者使用自己AI工具的账号及其费用。普通聊天软件收到仓库链接不等于安装成功，目前没有验证豆包直接运行本包。当前仅验证语文数学，不包含原著晨读材料、奖励物料或专项棋力题库。

## 这个Skill能做什么

- **建立学习档案**：分别记录每个孩子的年级、当前进度和练习量，使用代号即可。
- **生成可打印练习**：语文以动笔为主、范字适当轮换；数学组合出题，改变情境、条件和问法，不只换数字。题目与家长答案各一份PDF。
- **记录具体反馈**：保留原题、孩子实际答法及提示情况，区分漏做要求、计算错误和暂时未知的原因，也记录独立做对的表现。
- **据此调整下一套**：下一次先读本地档案和反馈，再安排新题、观察或适当轮换；不会因为出过一卷就认定孩子已经掌握。
- **接着用**：同一项目换聊天仍可读取本地档案；多个孩子分别保存。

使用流程：**告诉AI学习进度 → 建档 → 出卷并打印 → 反馈做题情况 → 调整下一套**。

中文名称是“**学习助手**”，英文程序标识是`child-practice`。支持Skill显示名称的工具会显示中文；保留英文目录和标识，已有安装方式与链接继续可用。

## 家长怎么开始

**不想手动下载？** 在能联网下载、读写本地文件并执行Python的AI桌面工具中，直接发送：

> 请从 https://github.com/shizilaoba001-collab/child-practice 下载并安装狮子老爸的“学习助手”。请你完成下载、解压、读取README和Skill说明、检查Python、安装依赖并实际运行doctor，不要只给我操作步骤。使用独立项目文件夹，保留已有学习资料。如果你没有下载或运行文件的权限，请直接告诉我，不要假装安装成功。安装成功后，先用简单的话告诉我能帮孩子练什么，再主动问我：孩子几年级、最近学到哪儿或想重点练什么、一次练多少合适。根据我的回答建立本地学习档案，生成可打印的语文数学练习，题目和答案分开。以后收到做题反馈，先记入档案，再调整下一套。不要让我写代码或编辑JSON，也不需要孩子真实姓名。

以下是手动下载的备选方式。

最短步骤见[给家长的三步启动说明](家长启动说明.md)。下载完整项目，不能只复制一个Skill文件。

下载解压整个文件夹，在支持本地Skill的AI工具中把它作为工作文件夹打开，然后发：

> 请使用这个项目的学习助手（child-practice）Skill，按README完成本地依赖检查和初始化。先问孩子的年级、目前语文数学进度，以及合适练习量；不需要真实姓名。学习资料放在本地user-data，别提交到Git。

以后只需在这个工作文件夹里说：

- “根据孩子的学习记录，出今天的语文数学练习，题目答案分开。”
- “这是刚才的答卷。请先记录实际错误和提示情况，再调整下一次。”

AI负责运行命令、写JSON与保存记录，家长不需要自己编辑这些文件。若换设备，需自行迁移整个user-data文件夹；只换聊天无需重建档案。不同AI工具的图片识别、出题能力、文件权限和成本仍会影响结果。

## 安装

- 需要Python 3.9+和首次安装依赖时的网络。字体已随包附带，无需安装系统字体。
- 在Codex等支持本地`.agents/skills`发现的工具中打开本项目后，可显式选择`child-practice`。其他宿主应按自身安装方式导入完整Skill文件夹，不能只复制SKILL.md。
- 独立复制`.agents/skills/child-practice/`也能安装，脚本和说明都在里面，不依赖仓库外的旧目录。
- 如果未显示Skill，让宿主检查其安装位置；不在不支持执行脚本的聊天软件中声称已安装。

让AI先运行`python3 install.py`（Windows可用`py install.py`），它只在本项目创建.venv、安装依赖并检查字体。等价手动步骤如下（Windows虚拟环境解释器为.venv/Scripts/python.exe）：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r .agents/skills/child-practice/requirements.txt
.venv/bin/python .agents/skills/child-practice/scripts/practice.py doctor
```

然后由AI按Skill向家长询问并执行init。详细输入格式在Skill的references目录。

## 隐私与当前状态

- 空白档案无真实孩子信息。测试案例为人工构造的虚拟学习者，不代表真实教学效果。
- `user-data/`、`.venv/`、测试输出已在`.gitignore`排除。提交代码前仍须检查暂存列表；忽略规则不代表所有第三方软件都不能上传。
- 字体来源及SIL OFL许可见`THIRD_PARTY_NOTICES.md`。包内字体为思源宋体/Noto Serif SC静态派生，已改名。
- 这是0.1.1分享版。脚本可复现不等于自动判断题目质量，也不等于家长端已试用通过。
